# 抖音直播页面优化 (Douyin Live Page Optimizer)

面向国内抖音直播页面的浏览器优化脚本（油猴 / Tampermonkey / Violentmonkey），自动整理直播界面、屏蔽干扰内容、提升流畅度，并提供常用快捷键。

## ✨ 功能特性

### 自动优化

- **自动关闭聊天室**：页面加载后自动收起右侧聊天室。
- **自动隐藏礼物栏**：隐藏直播底部的礼物面板。
- **自动切换「原画」画质**：检测到非原画时，自动进入画质菜单并切换到原画。
- **屏蔽礼物特效**：自动开启「屏蔽礼物特效」选项，避免满屏特效卡顿。
- **关闭送礼信息 / 福袋口令**：自动关闭弹幕中的送礼信息与福袋口令提醒。
- **清理引导弹窗**：隐藏登录引导、新手提示、送礼引导等干扰浮层，防 FOUC 闪烁。
- **后台切回防卡顿/黑屏**：切换标签页后唤醒视频渲染层；仅当离开前处于播放状态时恢复播放，尊重用户手动暂停。

### ⌨️ 快捷键

| 按键    | 功能                                                                |
| :------ | :------------------------------------------------------------------ |
| `C`     | 开 / 关 右侧聊天室                                                  |
| `空格`  | 暂停 / 继续播放                                                     |
| `Enter` | 唤醒底部栏并聚焦聊天输入框（再次按 Enter 可移出焦点，空内容不发送） |

> 提示：在输入框内打字时，`C` 键与空格键不会误触快捷键。

### ⚡ 性能优化

- 弹窗/元素监控观察器在 **2 分钟后自动销毁**，释放主线程、降低 CPU 占用。

## 📦 安装方法

1. 安装浏览器扩展：**Tampermonkey** 或 **Violentmonkey**。
2. 打开油猴扩展 →「新建脚本」→ 将本仓库 `douyin_live.js` 的完整内容粘贴进去并保存。
3. 打开抖音直播页面 `https://live.douyin.com/*`，脚本会自动运行。

## 🖥️ 适用范围

- 匹配地址：`https://live.douyin.com/*`
- 运行时机：`document-start`（尽早执行，避免闪烁）
- 兼容：Chrome / Edge / Firefox 等支持油猴的现代浏览器

## ⚠️ 注意事项

- 本脚本依赖抖音直播页面的 DOM 结构与 CSS 类名，若页面改版导致部分功能失效，需要同步调整选择器。
- 快捷键为页面级监听，若与浏览器或扩展快捷键冲突，请勿同时按住 `Ctrl` / `Alt` / `Win`（脚本会自动忽略组合键）。
- 若脚本未生效，请刷新页面并确认油猴扩展已启用、脚本处于「已启用」状态。

## 📁 文件说明

- `douyin_live.js`：直播页面优化脚本主体（匹配 `https://live.douyin.com/*`）。
- `douyin-video.js`：短视频网页版精简优化脚本（自改精简版，匹配 `https://www.douyin.com/*`，专注于短视频网页全屏、去冗余元素、自动最高画质等）。
- `README.md`：本说明文档。
