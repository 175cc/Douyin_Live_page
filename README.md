# 抖音直播页面优化

这是一个面向国内抖音直播页面的优化脚本，用于自动隐藏底部礼物栏、关闭聊天室、关闭弹幕礼物信息，并自动切换为原画画质。该脚本适用于浏览器油猴扩展（如 Tampermonkey、Violentmonkey 等）。

## 功能

- 自动关闭聊天室
- 自动隐藏直播底部礼物栏
- 自动屏蔽弹幕中的礼物信息和福袋口令
- 自动尝试切换为“原画”画质
- 支持按 `C` 键切换聊天室显示/隐藏

## 适用范围

适用于国内抖音直播页面：`live.douyin.com`

## 安装方法

1. 安装浏览器油猴扩展：Tampermonkey、Violentmonkey 等。
2. 下载或复制本仓库中的 `抖音直播.js` 文件内容。
3. 在油猴中创建新脚本，将内容粘贴进去并保存。
4. 打开抖音直播页面后，脚本会自动运行。

## 使用说明

- 打开抖音直播页面后，脚本会在页面加载完成后自动执行。
- 如果聊天室未自动关闭，可按键盘 `C` 键切换聊天室显示/隐藏。
- 脚本会自动尝试选择“原画”画质并关闭礼物特效。

## 注意事项

- 本脚本依赖抖音直播页面元素结构，若页面更新可能需要调整选择器。
- 若脚本未生效，可尝试刷新页面或检查油猴扩展是否启用。
